# Архитектура и экраны Telegram WebApp «Appex ADIPEC Concierge»

## Экран 1. Авторизация и Безопасность (Вход для VIP)

Так как это элитный продукт, первый экран должен выглядеть строго и
конфиденциально.

### Визуал

-   Темная премиальная тема (Deep Charcoal/Gold).
-   Логотип Appex Asset Suite и АО «НК «Казмунайгаз».

### Логика

-   Вход по корпоративной почте (`@kmg.kz`) или по индивидуальному
    токену-приглашению.

### Элемент

> «Доступ разрешен только верифицированным делегатам КМГ».

------------------------------------------------------------------------

## Экран 2. Главная панель делегата (Dashboard)

Центральный хаб управления поездкой.

### Блок 1. Статус

-   Имя делегата.
-   Должность в КМГ.
-   Кнопка **SOS / Экстренная связь**.

### Блок 2. Расписание

-   Интерактивный календарь ADIPEC, куда аналитики заранее занесли
    ключевые сессии КМГ.

### Блок 3. Навигация

Кнопки быстрого перехода: - Мой Автопарк - B2B Нетворкинг - Инвест-Лоты

------------------------------------------------------------------------

## Экран 3. Модуль «Мой Автопарк в Абу-Даби»

Демонстрирует КМГ, как клуб решает логистическую проблему и экономит
бюджет.

### Интерфейс

Список закрепленных за КМГ автомобилей: - Mercedes-Benz S-Class -
Maybach - Премиум-минивэны

### Функционал

-   Карта в реальном времени (местоположение водителя).
-   Кнопка **«Вызвать авто к павильону №X»** (запрос отправляется
    локальному подрядчику Appex в ОАЭ через API).
-   Фото и контакты личного англо-/русскоговорящего водителя.

------------------------------------------------------------------------

## Экран 4. Модуль «B2B Нетворкинг и Переговоры»

### Интерфейс

Карточки топ-менеджеров зарубежных компаний: - ADNOC - Saudi Aramco -
Total

Встречи предварительно согласованы клубом Appex.

### Функционал

-   Кнопка **«Посмотреть досье компании»** (краткая аналитика от
    студентов).
-   Таймер до начала встречи.
-   Номер VIP-лаунжа ADIPEC, где пройдут переговоры.

------------------------------------------------------------------------

## Экран 5. Модуль «Инвестиционные лоты (Appex Asset Suite)»

Закрытый каталог премиальных активов, доступных для инвестирования во
время поездки.

### Разделы

#### Недвижимость

-   Коммерческие площади в Абу-Даби рядом с экспо-центром.
-   Доходность (ROI) от **8% годовых**.

#### Авто-пулы

-   Возможность коллективного выкупа эксклюзивных автомобилей напрямую с
    заводов.

------------------------------------------------------------------------

# Техническое задание (ТЗ)

## Задача

Разработать Frontend-прототип Telegram WebApp (мини-приложение).

## Стек

-   HTML5
-   CSS3 (Tailwind CSS)
-   JavaScript / TypeScript
-   React или Vue

## Дизайн

-   Минимализм.
-   Темные тона (`#1A1A1A`, `#D4AF37`).
-   Крупные читаемые шрифты.

## Критерий успеха

-   Приложение открывается внутри Telegram.
-   Переключение между 5 экранами происходит без задержек.
-   Реализована имитация отправки запросов (вызов автомобиля, открытие
    карты встреч).
-   Все демонстрационные данные (имена, автомобили, компании)
    захардкожены.

## Срок

**5 дней.**
